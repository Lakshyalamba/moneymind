# Webhook Subscriptions and Signature Verification in MoneyMind

MoneyMind exposes a secure webhook event pipeline to notify third-party integrations when financial events occur.

---

## 1. Event Types

The pipeline currently fires the following event types:
- `transaction.created`: Fired when a new transaction is logged
- `transaction.updated`: Fired when a transaction is modified
- `transaction.deleted`: Fired when a transaction is deleted
- `budget.exceeded`: Fired when category spending exceeds the defined limit
- `goal.completed`: Fired when a savings goal is 100% completed
- `subscription.upcoming`: Fired when a recurring subscription renewal is imminent (3 days prior)

---

## 2. Dispatch Payload Schema

All webhook requests are sent as `POST` requests with a JSON body:

```json
{
  "eventId": "e9bf6bfd-46d5-455f-bb5c-7ec6d8177dfa",
  "timestamp": "2026-08-25T13:30:00.000Z",
  "eventType": "transaction.created",
  "payloadVersion": "1.0",
  "data": {
    "id": 12,
    "amount": 150.50,
    "type": "expense",
    "category": "Shopping",
    "note": "Books purchase",
    "date": "2026-08-25"
  }
}
```

---

## 3. Verifying HMAC Signatures

To ensure webhook requests are authentic and generated by MoneyMind, each request is signed with the subscription's `secret` key.

Verify the signature using your secret inside your receiver application:

### Node.js Verification Example

```javascript
import crypto from 'crypto';

const verifyWebhook = (reqBodyString, headerSignature, secret) => {
  const calculatedSignature = crypto
    .createHmac('sha256', secret)
    .update(reqBodyString)
    .digest('hex');

  return calculatedSignature === headerSignature;
};
```
The signature is sent in the request headers under:
`X-MoneyMind-Signature`

---

## 4. Retries and Failure Handling

If your server returns a non-2xx status code or is unreachable, the MoneyMind dispatcher automatically schedules a retry up to **3 times** using exponential backoff (e.g. 2s, 4s delays).
Each attempt header is passed as:
`X-MoneyMind-Attempt`
